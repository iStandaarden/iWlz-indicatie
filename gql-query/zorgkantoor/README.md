# Query-templates voor het Zorgkantoor

Hier staan de query templates die het zorgkantoor kan gebruiken voor het raadplegen van gegevens in het Indicatieregister. De templates dienen als voorbeeld hoe de query opgebouwd moet worden. De structuur en bepaalde verplichte parameters zijn nodig om te voldoen aan de autorisatie-policies.

Ga naar [Raadplegen](/iWlz-indicatie/raadplegen/README.md) voor meer uitleg.
